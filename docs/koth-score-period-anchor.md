# KOTH 점수 조회 시각

플랫폼의 period_id는 항상 15분 구간의 시작 시각입니다
문제 서버가 종료 시각을 받는 경우 관리자의 score_period_anchor를 END로 설정합니다

| 설정 | 플랫폼 이력 | 문제 서버 조회 |
|---|---|---|
| START | 08:30–08:45 구간 → 08:30 | period_id=08:30, scored_at=08:30 |
| END | 08:30–08:45 구간 → 08:30 | period_id=08:45, scored_at=08:45 |

기본값 START는 기존 문제에 적용합니다
Dependency Hell은 제출 접수 시각을 period_id 경계까지 읽으므로 END를 사용합니다
기존 koth-dependency-hell 항목은 마이그레이션에서 END로 설정합니다
새로 등록할 때는 관리자 문제 생성·수정 API에 score_period_anchor를 명시합니다
관리자 조회 응답에도 현재 설정이 포함됩니다

문제 서버의 응답은 원문 그대로 저장합니다
응답의 구간 시각은 설정에 맞게 검사하고, 플랫폼의 이력·중복 방지 키는 시작 시각을 유지합니다
이미 반영된 이력과 점수는 설정을 바꾸거나 마이그레이션해도 다시 지급하지 않습니다
이전 설정으로 비어 있는 결과가 확정됐다면 기존 이력을 별도로 대조해야 합니다

출제자 문제 코드와 채점 방식은 변경하지 않습니다
