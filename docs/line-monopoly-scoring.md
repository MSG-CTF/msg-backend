# 라인 독점 점수

한 라인의 문제 5개를 모두 해결하면 팀당 해당 라인에서 300점을 한 번 지급

- 문제의 동적 배점과 분야 구성에 관계없이 300점 고정
- 6개 라인을 모두 완성하면 총 1,800점
- 같은 라인은 여러 팀이 각각 완성하고 보너스를 받을 수 있음
- 룰렛 같은 특수 칸 방문 여부는 완성 조건에서 제외
- 마지막 문제의 정답 처리 트랜잭션에서 지급 기록을 생성하고 총점에 즉시 합산
- 라인 보너스는 해결 문제 수에 추가하지 않음

총점은 제오파디 현재 배점 합계, KOTH 점수, 부스 문제 점수, 지급한 라인 보너스의 합

기존 30%와 같은 분야 45% 계산 및 관리자 비율 설정을 제거
이전 설정이 데이터베이스에 남아 있어도 새 지급액에 영향을 주지 않음
기존 API의 is_category_bonus 필드는 호환성을 위해 유지하며 새 기록에는 false를 저장

이 변경은 신규 지급 규칙을 바꾸며, 기존 지급 기록과 관리자의 수동 점수 보정은 자동으로 덮어쓰지 않음
