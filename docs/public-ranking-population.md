# 공개 순위의 참가팀 범위

전체 팀 순위, 내 팀 순위, 개인 순위와 상위 팀 점수 그래프는 관리자 기본 팀 목록과 KOTH가 사용하는 `eligible_teams()`의 참가팀 범위를 공유한다

- 정지된 팀과 명시적으로 테스트 분류된 팀을 조회 대상에서 제외한다
- 필터를 순위 계산과 페이지 분할 전에 적용하므로 순번과 `total_count`에도 테스트 팀이 포함되지 않는다
- 아직 계정이나 풀이 기록이 없는 정식 팀은 전체 순위에 남는다
- 팀 이름이 테스트 이름과 비슷해도 분류 표식이 없으면 이름만으로 제외하지 않는다
- 테스트 팀의 내 팀 순위와 개인 순위 조회는 기존 집계 제외 팀과 같이 성공 응답의 `data: null`을 반환한다

이 변경은 조회 대상만 제한하며 계정, 소속, 비밀번호, 팀 점수, 풀이 기록과 테스트 분류를 수정하지 않는다
DB 마이그레이션이나 운영 데이터 정리 명령은 필요하지 않다

회귀 검증은 높은 점수의 테스트 팀, 중복 분류 표식, 오래된 표식, 정지된 팀, 계정이 없는 정식 팀, 테스트와 비슷한 이름의 정식 팀, 순번과 페이지 수, 조회 전후 데이터 보존을 포함한다
