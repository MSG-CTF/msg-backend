# 사이트별 순위 조회 범위

외부 서버는 외부 참가팀만, 내부 서버는 내부 참가팀만 순위에 표시한다
운영 명단의 팀 UUID를 지정해 같은 부문에 새 검증용 팀이 생성돼도 공개 순위에 포함되지 않도록 한다

- `PUBLIC_RANKING_DIVISION`: `EXTERNAL` 또는 `INTERNAL`, 기본값은 외부 서버용 `EXTERNAL`
- `PUBLIC_RANKING_TEAM_IDS`: 쉼표로 나눈 해당 서버의 정식 참가팀 UUID 명단
- `PUBLIC_RANKING_EXCLUDED_TEAM_IDS`: 기존 내부 서버의 명시적 검증팀 제외 설정과 호환되는 선택 항목

운영에서는 외부 명단 50개 UUID, 내부 명단 25개 UUID를 각각 설정한다
명단 설정이 없는 개발·테스트 환경에서는 해당 부문의 등록된 참가팀을 조회한다
부문과 UUID 형식은 시작 시 검증하며 요청의 Host, 사용자 소속, query 값으로 서버의 조회 범위를 변경하지 않는다

전체 순위, 내 팀 순위, 개인 순위, 상위 점수 그래프와 KOTH 화면의 문제별 순위에 같은 조회 범위를 적용한다
순위와 페이지 수는 필터링한 목록에서 계산하고 KOTH 표시 캐시는 부문·명단·제외 UUID가 다른 설정 사이에서 공유하지 않는다

계정, 비밀번호, 소속, 팀의 부문 값, 점수와 풀이 기록을 수정하지 않는다
KOTH 게임 서버에 제공하는 참가팀 목록과 실제 점수 지급 로직은 기존의 전역 참가팀 범위를 유지한다
DB 마이그레이션이나 운영 데이터 정리 작업은 필요하지 않다
