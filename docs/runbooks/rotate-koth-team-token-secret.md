# KOTH_TEAM_TOKEN_SECRET 교체 절차

KOTH 팀 토큰은 `KOTH_TEAM_TOKEN_SECRET`을 키로 HMAC해서 결정적으로 만들어지므로, 비밀값이 바뀌면 이전 토큰도 함께 폐기해야 한다. 아래 순서대로 진행한다.

## 사전 준비

- 교체 담당자 1명과 입회자 1명(가능하면 다른 팀원) 지정
- 교체 시작 전 배포가 멈춘 상태인지 확인
- 폐기 전후를 비교할 수 있도록 현재 `koth_team_tokens` 행 수 조회
- 교체 이력 기록용 티켓 또는 이슈 하나 열기

## 교체 순서

1. **새 비밀값 생성**
   결과를 티켓이나 비밀 관리 도구에만 저장한다. 평문을 채팅·커밋에 남기지 않는다.

2. **운영 `.env`의 `KOTH_TEAM_TOKEN_SECRET`을 새 값으로 교체**
   - `JWT_SECRET`과 다른 값인지 반드시 확인한다. 같은 값이면 서버가 시작을 거부한다.
   - 변경 시각을 기록한다.

3. **백엔드 서비스 재시작**
   - 재시작 로그에서 `ImproperlyConfigured`가 뜨지 않는지 확인한다.

4. **기존 팀 토큰 해시 폐기**
   `폐기 완료: N개의 팀 토큰 해시가 삭제됐습니다.` 메시지가 뜨면 성공이다.

5. **검증**
   - `SELECT COUNT(*) FROM koth_team_tokens;` 결과가 0인지 확인한다.
   - 참가자용 안내 채널에 토큰 재발급이 필요하다는 공지를 올린다.
   - 선수는 로그인 상태에서 `POST /api/v1/koth/team_token`으로 새 토큰을 재발급 받는다.

## 롤백 기준

아래 중 하나라도 발생하면 롤백한다.
- 서버 재시작 실패(새 값이 비어 있거나 `JWT_SECRET`과 같음)
- `rotate_koth_team_token_secret` 명령이 오류로 끝남
- 교체 직후 다수의 선수가 토큰 재발급을 받지 못함

롤백 절차: `.env`를 교체 전 값으로 되돌리고 서버를 재시작한다. 폐기된 해시는 복구할 수 없으므로, 선수는 그대로 재발급을 받으면 된다.

## 교체 기록 양식

이슈나 티켓에 아래 정보를 남긴다.
- 교체 담당자 / 입회자
- 교체 시작·완료 시각
- 교체 전·후 `koth_team_tokens` 행 수
- 재발급 공지 시각
- 이상 유무 및 비고
