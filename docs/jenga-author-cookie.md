# 출제자 Jenga 쿠키 연동

출제자 최신 버전은 jenga_session 쿠키를 사용한다
기존 플랫폼 미리보기는 session만 찾기 때문에 새 원본 서버의 로그인 결과를 읽지 못한다

플랫폼에서 두 형식을 받아 배포 전후를 지원한다
로그인 응답에 실제로 들어온 쿠키 이름과 값을 미리보기 세션에 묶는다
두 이름의 쿠키를 한 요청에 섞거나 로그인 응답이 두 인증 쿠키를 함께 주면 차단한다
새 미리보기를 발급할 때는 Jenga의 이전·현재 쿠키를 함께 지운다

게임 이미지·출제자 코드·쿠키 내용은 변경하지 않는다
다른 게임의 쿠키 이름과 미리보기 인증 조건도 유지한다
기존 Jenga 미리보기 연결 중 쿠키 이름을 기록하지 않은 세션은 다시 로그인해야 한다
